# CatPose 参考文献、链接与技术说明

本文列出项目中用到的全部数据集、预训练模型、论文方法、软件库和外部链接，并说明每一项在项目里的具体用途。

---

## 1. 数据集

### 1.1 CatFLW（猫脸 48 个关键点）

- **用途**：训练脸部关键点模型（`face.pt`）
- **规模**：2079 张猫脸图片，每张标注 48 个关键点和一个脸部框。本项目划分为 1872 张训练、207 张验证。
- **代码仓库**：https://github.com/martvelge/CatFLW
- **下载（Kaggle）**：https://www.kaggle.com/datasets/georgemartvel/catflw
- **数据集论文**：Martvel, Farhat, Shimshoni, Zamansky. *CatFLW: Cat Facial Landmarks in the Wild Dataset.* arXiv:2305.04232, 2023. https://arxiv.org/abs/2305.04232
- **检测方法论文**：Martvel, Shimshoni, Zamansky. *Automated Detection of Cat Facial Landmarks.* International Journal of Computer Vision, 2024. https://link.springer.com/article/10.1007/s11263-024-02006-w
- **48 点方案来源**：Finka et al. 2019, *Scientific Reports*. https://www.nature.com/articles/s41598-019-46330-5
- **相关编码体系**：CatFACS（猫面部动作编码系统）https://animalfacs.com/catfacs_new
- **制作方**：Tech4Animals Lab，海法大学 https://www.tech4animals.org
- **许可证**：**CC BY-NC 4.0（署名-非商业性使用）** https://creativecommons.org/licenses/by-nc/4.0/

> ⚠️ **使用限制**：用 CatFLW 训练出的脸部模型权重不能用于商业用途。分享给组员用于研究和学习没有问题。

### 1.2 Animal Pose Dataset（动物身体 20 个关键点）

- **用途**：训练身体关键点模型（`body.pt`）
- **规模**：共 6117 个标注实例，覆盖猫、狗、羊、马、牛五个物种，所有物种共用同一套 20 点定义。其中猫 1466 个：Part II 自采集集 200 张，其余来自 PASCAL VOC 图片。
- **20 个点**：左眼、右眼、鼻、左耳、右耳、四个肘、四个膝、四个爪、喉、肩胛（withers）、尾根
- **代码仓库**：https://github.com/noahcao/animal-pose-dataset
- **项目主页**：https://sites.google.com/view/animal-pose/
- **论文**：Cao, Tang, Fang, Shen, Lu, Tai. *Cross-Domain Adaptation for Animal Pose Estimation.* ICCV 2019. https://openaccess.thecvf.com/content_ICCV_2019/html/Cao_Cross-Domain_Adaptation_for_Animal_Pose_Estimation_ICCV_2019_paper.html
- **标注下载**：通过仓库 README 中的 Google Drive 链接获取（Part I 与 Part II）

### 1.3 PASCAL VOC 2012（补全 Animal Pose 的图片）

- **用途**：Animal Pose 的 Part I 标注指向 VOC 图片，本项目下载后只解出需要的 3608 张。
- **官方主页**：http://host.robots.ox.ac.uk/pascal/VOC/voc2012/
- **实际下载地址（镜像）**：https://pjreddie.com/media/files/VOCtrainval_11-May-2012.tar（1.9 GB，解压后已删除原包）
- **论文**：Everingham, Van Gool, Williams, Winn, Zisserman. *The PASCAL Visual Object Classes (VOC) Challenge.* International Journal of Computer Vision, 2010.

### 1.4 COCO（检测器的预训练数据）

- **用途**：YOLOv8 在 COCO 上预训练，本项目只用其中第 15 类 "cat"，不重新训练检测器。
- **主页**：https://cocodataset.org
- **论文**：Lin et al. *Microsoft COCO: Common Objects in Context.* ECCV 2014. https://arxiv.org/abs/1405.0312

### 1.5 ImageNet（骨干网络预训练）

- **用途**：MobileNetV3 骨干使用 torchvision 提供的 ImageNet 预训练权重作为起点。

## 3. 方法与论文

### 3.1 网络结构

| 方法 | 在本项目中的作用 | 参考 |
|---|---|---|
| **MobileNetV3** | 关键点模型的骨干网络，轻量、适合实时 | Howard et al. *Searching for MobileNetV3.* ICCV 2019. https://arxiv.org/abs/1905.02244 |
| **Squeeze-and-Excitation（SE）** | MobileNetV3 内部的通道注意力模块 | Hu, Shen, Sun. *Squeeze-and-Excitation Networks.* CVPR 2018. https://arxiv.org/abs/1709.01507 |
| **Feature Pyramid Network（FPN）** | v2 融合 1/8、1/16、1/32 三个尺度的特征 | Lin et al. *Feature Pyramid Networks for Object Detection.* CVPR 2017. https://arxiv.org/abs/1612.03144 |
| **YOLOv8** | 猫检测器（CSPDarknet 骨干 + PANet 特征金字塔 + 检测头） | Ultralytics 文档 https://docs.ultralytics.com ，代码 https://github.com/ultralytics/ultralytics |

### 3.2 关键点回归方法

| 方法 | 在本项目中的作用 | 参考 |
|---|---|---|
| **热力图关键点检测** | v2 的核心改动：每个关键点输出一张位置概率图 | Xiao, Wu, Wei. *Simple Baselines for Human Pose Estimation and Tracking.* ECCV 2018. https://arxiv.org/abs/1804.06208 |
| **Integral Regression / soft-argmax** | 从热力图取概率加权的期望坐标，可微分且亚像素精度 | Sun et al. *Integral Human Pose Regression.* ECCV 2018. https://arxiv.org/abs/1711.08229 |
| **DSNT + 热力图正则** | 坐标损失之外，加一项与高斯目标之间的 KL 散度，让热力图更集中 | Nibali et al. *Numerical Coordinate Regression with Convolutional Neural Networks.* 2018. https://arxiv.org/abs/1801.07372 |
| **全局回归（v1 做法）** | 骨干 → 全局平均池化 → MLP 直接输出坐标，已被 v2 替换 | — |

### 3.3 训练技术

| 技术 | 在本项目中的作用 | 参考 |
|---|---|---|
| **AdamW** | 优化器 | Loshchilov, Hutter. *Decoupled Weight Decay Regularization.* ICLR 2019. https://arxiv.org/abs/1711.05101 |
| **余弦学习率 + 预热** | 学习率调度 | Loshchilov, Hutter. *SGDR: Stochastic Gradient Descent with Warm Restarts.* ICLR 2017. https://arxiv.org/abs/1608.03983 |
| **Smooth L1 损失** | v1 的坐标损失 | Girshick. *Fast R-CNN.* ICCV 2015. https://arxiv.org/abs/1504.08083 |
| **迁移学习 / 两阶段微调** | 先在 5 种动物上预训练，再只用猫微调 | Cao et al. ICCV 2019（见 1.2，跨物种迁移思路） |
| **仿射数据增强** | 缩放、平移、±30° 旋转、翻转；越界部分补黑边 | 通用做法，实现见 `transforms.py` |
| **匈牙利算法** | 自动推导 CatFLW 48 点的左右对称映射 | Kuhn 1955；实现：SciPy `linear_sum_assignment` https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linear_sum_assignment.html |

### 3.4 推理技术

| 技术 | 在本项目中的作用 | 参考 |
|---|---|---|
| **测试时翻转增强（TTA）** | 原图和镜像各推理一次，把镜像结果按左右映射换回后取平均 | 关键点领域的常规做法 |
| **级联精修（两遍脸部）** | 第二遍用第一遍的点重建标准脸框再预测，误差 1.58% → 1.19% | 本项目实验，脚本 `ml/scripts/face_refine_experiment.py` |
| **One-Euro 滤波** | 帧间平滑：静止时强平滑去抖，快速运动时降低延迟 | Casiez, Roussel, Vogel. *1€ Filter: A Simple Speed-based Low-pass Filter for Noisy Input in Interactive Systems.* CHI 2012. https://gery.casiez.net/1euro/ |
| **非极大值抑制（NMS）** | YOLO 去除重复检测框 | 内置于 Ultralytics |

### 3.5 评估指标

| 指标 | 含义 |
|---|---|
| **PCK@α** | 预测点与真值的距离小于 α × 框的长边即算命中，本项目报告 α = 0.05 和 0.1 |
| **NME** | 平均误差 ÷ √(框宽 × 框高)，越低越好 |
| **检测召回率** | 验证图中被检测出猫的比例 |

## 5. 项目流水线里各技术的位置

```
摄像头帧（OpenCV 或浏览器 getUserMedia）
  │
  ▼
YOLOv8s（Ultralytics，COCO 预训练）→ 猫框         ← 修复：numpy 输入必须是 BGR
  │
  ▼
仿射裁剪 256×256 + ImageNet 归一化
  │
  ▼
身体模型：MobileNetV3-large + FPN + 热力图 + soft-argmax + 翻转 TTA
  │   → 20 个点 + 置信度 → One-Euro 平滑
  ▼
用可信的头部 5 点推出脸框
  │
  ▼
脸部模型（同一结构，CatFLW 训练），跑两遍级联精修
  │   → 48 个点 + 置信度 → One-Euro 平滑
  ▼
JSON（FastAPI）/ 叠加图 / OpenCV 数据面板
```
