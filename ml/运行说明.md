# CatPose 本机运行说明

这份文档假设你人在项目根目录：

```bash
cd catpose-robot   # 仓库根目录
```

以下所有命令都从这个目录出发。

---

## 0. 一次性前置检查（首次跑之前，或换机器后）

**看虚拟环境是否存在**：

```bash
ls ml/.venv/bin/python && ml/.venv/bin/python --version
```

看到 `Python 3.9.x` 就 OK。看不到就先建 venv（首次配置）：

```bash
python3 -m venv ml/.venv && ml/.venv/bin/pip install --upgrade pip
```

**看三个权重文件是否都在**：

```bash
ls -la ml/checkpoints/
```

应该看到 `face.pt`、`body.pt`、`yolov8n.pt` 三个文件。缺哪个跳到下面对应章节补。

**看端口 8080 是否被占**：

```bash
lsof -i :8080 -sTCP:LISTEN
```

- 有输出说明服务器已经在跑（可能是我之前给你留的那个）——**你可以直接跳到第 2 章打开浏览器**。
- 没输出说明端口空闲——进第 1 章启动服务。

---

## 1. 启动 FastAPI 服务器

**推荐：前台启动（关掉终端就停止，最简单）**

```bash
PYTHONPATH=ml ml/.venv/bin/uvicorn catpose.service:app --port 8080
```

启动后终端会打印类似：
```
INFO:     Uvicorn running on http://127.0.0.1:8080
INFO:     Application startup complete.
```

**如果想让服务器后台跑（关掉终端也不停）**：

```bash
PYTHONPATH=ml nohup ml/.venv/bin/uvicorn catpose.service:app --port 8080 > /tmp/catpose.log 2>&1 &
echo $! > /tmp/catpose.pid
```

后面用这条命令看日志：

```bash
tail -f /tmp/catpose.log
```

想停掉后台服务器：

```bash
kill "$(cat /tmp/catpose.pid)" 2>/dev/null && rm /tmp/catpose.pid
```

**如果端口 8080 已被别的东西占用**，换个端口：

```bash
PYTHONPATH=ml ml/.venv/bin/uvicorn catpose.service:app --port 8090
```

（后面的 URL 也要相应改成 `http://localhost:8090/`）

---

## 2. 打开浏览器 Dashboard（用摄像头实时识别）

**必须用真实浏览器**（Safari / Chrome / Firefox），Claude 内置浏览器拿不到摄像头权限。

```bash
open http://localhost:8080/
```

页面打开后：

1. 右上角三个绿点亮起 = face / body / YOLO 三个模型都加载好了
2. 点 **Start camera** 按钮 → 系统弹窗要摄像头权限，同意
3. 右侧面板开始实时刷新：detected class、confidence、bbox、face 48 点坐标、body 20 点坐标、耗时分解
4. 左边视频窗口叠加：绿虚线框 = YOLO 猫框，红点 = 脸 48 点，橙色点+骨架 = 身体 20 点
5. 想调 FPS 用 **Target FPS** 滑块（默认 3，可调 1–10）
6. 点 **Stop** 关掉摄像头

**如果浏览器不给摄像头权限**：系统设置 → 隐私与安全性 → 摄像头 → 勾上你的浏览器，然后刷新页面。

**用 curl 快速验证服务器是否活着**：

```bash
curl -s http://localhost:8080/health | python3 -m json.tool
```

四个字段都是 `true` 就正常。

## 3. 命令行实时识别（不用浏览器，两个 OpenCV 窗口）

### 3a. 推荐：摄像头窗口 + 数据面板 + YOLO 自动检测（一条命令）

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.realtime --detect
```

会弹出**两个 OpenCV 窗口**，同时终端里滚动一行实时状态：

- **`catpose · camera`** — 摄像头画面 + YOLO 绿框（`cat 91%`）+ 红脸 48 点 + 橙色身体骨架 + 左上角 FPS
- **`catpose · data`** — 深色数据面板：检测类别、置信度、耗时分解、bbox、身体前 8 个关键点（带名字）+ 脸前 6 个关键点
- **终端里**每帧刷新一行：`frame=42 | fps=9.5 | det=cat | conf=91% | kp_face=48 | kp_body=20 | t_yolo=68ms | t_kp=188ms`

按 `q` 或 `Esc` 关掉任一窗口即退出。

### 3b. 常用变体

**只要摄像头窗口，不要数据面板**：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.realtime --detect --no-data
```

**关掉终端刷屏（只留窗口）**：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.realtime --detect --no-print
```

**不用 YOLO，直接把整帧当 bbox**（省 ~70 ms/帧，能到 ~15 FPS，但检测框跟随不到位）：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.realtime
```

**换摄像头**（0 是默认，1 是外接 USB 摄像头）：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.realtime --detect --source 1
```

**v2 新增选项**（默认值已调好，一般不用改）：

- `--device cpu`：没有 Apple GPU 时改用 CPU（v2 模型在 CPU 上较慢，约 2 FPS）
- `--min-conf 0.4`：只显示更有把握的点（默认 0.25）
- `--face-passes 1`：脸部只跑一遍（默认 2 遍，更准）
- `--no-smooth`：关闭时序平滑，看模型原始输出
- `--yolo-ckpt ml/checkpoints/yolov8n.pt`：换回更小的检测器
- 想回退到 v1 模型：`--face-ckpt ml/checkpoints/face_v1.pt --body-ckpt ml/checkpoints/body_v1.pt`

**调 YOLO 检测频率**（默认每 3 帧检测一次，中间用缓存的 bbox；改成 1 = 每帧都检测，更准更慢）：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.realtime --detect --detect-every 1
```

**跑视频文件而不是摄像头**：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.realtime --source /path/to/your/video.mp4
```

**处理视频并写出带标注的新 mp4（无窗口，纯后台）**：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.realtime \
    --source /path/to/input.mp4 \
    --output /path/to/output-annotated.mp4 \
    --no-display
```

**只跑一个模型加速**（Mac CPU 上双模型 ~9 FPS，单模型 ~18 FPS）：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.realtime --skip-face
PYTHONPATH=ml ml/.venv/bin/python -m catpose.realtime --skip-body
```

## 4. 用 API 处理单张图片（不用摄像头）

服务器起来后可以直接 curl。**替换 `path/to/cat.jpg` 为你的图片路径**。

**只要脸 48 点**：

```bash
curl -s -F "image=@path/to/cat.jpg" http://localhost:8080/predict/face | python3 -m json.tool
```

**只要身体 20 点**：

```bash
curl -s -F "image=@path/to/cat.jpg" http://localhost:8080/predict/body | python3 -m json.tool
```

**YOLO 自动检测 + 脸 + 身体 一次搞定**：

```bash
curl -s -F "image=@path/to/cat.jpg" http://localhost:8080/predict/auto | python3 -m json.tool
```

**直接得到叠加了关键点的 PNG**：

```bash
curl -s -F "image=@path/to/cat.jpg" \
     "http://localhost:8080/predict/auto/image?include_data=false" \
     -o /tmp/cat-annotated.png && open /tmp/cat-annotated.png
```

**用仓库自带的一张猫图快速试**（不用你自己的图）：

```bash
SAMPLE=$(ls ml/datasets/AnimalPose/animalpose_image_part2/cat/*.jpeg | head -1)
curl -s -F "image=@$SAMPLE" "http://localhost:8080/predict/auto/image?include_data=false" -o /tmp/demo.png && open /tmp/demo.png
```

## 5. 重新训练模型（如果你想改架构或加数据）

**先跑数据校验**（确认两个数据集读得出来）：

```bash
./ml/scripts/run_dataset_tests.sh
```

**训身体模型**（约 5 分钟 CPU，180 张训练图）：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.train --kind body --epochs 20 --batch-size 16 --cpu
```

**训脸模型**（约 15 分钟 CPU，1872 张训练图）：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.train --kind face --epochs 6 --batch-size 32 --cpu
```

**一起训（脸+身体依次跑）**：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.train --kind both --cpu
```

训完新的 `face.pt` / `body.pt` 会自动覆盖 `ml/checkpoints/` 里的老权重。**服务器不需要重启**——新请求会用新权重（因为服务器每次收到请求都从磁盘 lazy load）……实际上不会，`_face` 和 `_body` 是常驻内存的，改完权重要重启服务器：

```bash
# 停旧服务器
kill "$(cat /tmp/catpose.pid)" 2>/dev/null

# 再按第 1 章的命令重启
```

**冒烟测试（1 个 epoch × 32 张，30 秒内跑完，用来验证代码能跑）**：

```bash
PYTHONPATH=ml ml/.venv/bin/python -m catpose.train --kind body --epochs 1 --limit 32 --workers 0 --batch-size 8 --cpu
```

## 6. 补权重（缺文件的情况）

**缺 YOLO** 权重（第一次跑 detector 或不小心删了）：

```bash
ml/.venv/bin/python -c "from ultralytics import YOLO; YOLO('yolov8n.pt')" && mv yolov8n.pt ml/checkpoints/
```

**缺 face.pt / body.pt**：只能重新训（见第 5 章）。

## 7. 常见问题排查

**问题：浏览器打开 `http://localhost:8080/` 显示不出来**

```bash
# 看服务器进程还在不
ps -ef | grep uvicorn | grep -v grep

# 看端口
lsof -i :8080 -sTCP:LISTEN

# 看健康检查
curl -s http://localhost:8080/health
```

三个都没回应 → 服务器挂了，回第 1 章重启。

**问题：右上角三个绿点里 YOLO 是红的**

```bash
ls ml/checkpoints/yolov8n.pt
```

不存在 → 回第 6 章补 YOLO。

**问题：Dashboard 显示 `Camera unavailable: Permission denied`**

macOS：系统设置 → 隐私与安全性 → 摄像头 → 打开你的浏览器开关，然后刷新页面。

**问题：识别很卡（FPS 掉到 1 以下）**

- Dashboard 里 **Target FPS 滑块调到 2 或 1**
- 或者用 `--skip-face` / `--skip-body` 只跑一个模型（第 3 章）

**问题：YOLO 检测框跳来跳去 / 检测不到猫**

- 猫离摄像头近一点、增强光线
- 已经加了 dog / horse / sheep / cow 的兜底类，认成狗也会给出 bbox
- 完全没检测到时会自动用整帧当 bbox（右侧面板会显示 `detected class: none (using whole frame)`）

**问题：改了 Python 代码但服务器行为没变**

服务器需要重启（uvicorn 默认不监控代码改动）。想开发时自动重启：

```bash
PYTHONPATH=ml ml/.venv/bin/uvicorn catpose.service:app --port 8080 --reload
```

**问题：想看服务器实时日志**（后台跑的话）：

```bash
tail -f /tmp/catpose.log
```

cat /tmp/uvicorn.pid 2>/dev/null && lsof -i :8080 -sTCP:LISTEN
