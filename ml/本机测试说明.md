# 猫关键点数据集：本机测试说明

## 你现在能测试什么？

目前电脑里**还没有训练好的 AI 模型**。因此现在运行的是“数据集标注测试”：程序读取人工标注的关键点，并把它们画回猫图片上。

这一步用来确认三件事：

1. CatFLW 的猫脸图片与 48 个脸部点能被正确读取；
2. Animal Pose 的猫身体图片与 20 个身体点能被正确读取；
3. 后面训练模型时，输入和正确答案的格式是可用的。

它**不代表 AI 已经识别情绪**，也不代表模型已经训练完成。

## 一次完成全部测试

1. 打开 Terminal（终端）。
2. 复制并运行以下两行：

```bash
cd catpose-robot   # 仓库根目录
./ml/scripts/run_dataset_tests.sh
```

成功时会看到：

```text
CatFLW: 2079 images, 2079 labels; sample has 48 landmarks and bbox length 4.
Animal Pose: ... sample keypoints: 20.
Ready for landmark-training setup.
```

并生成两张测试图：

- `ml/outputs/catflw-face-landmarks.png`：猫脸的蓝色框与 48 个红点；
- `ml/outputs/animalpose-cat-keypoints.png`：猫身体的红点与蓝色骨架线。

## 分开测试

### A. 只测试 CatFLW（脸部 48 点）

```bash
cd catpose-robot   # 仓库根目录
ml/.venv/bin/python ml/scripts/check_pose_datasets.py
ml/.venv/bin/python ml/scripts/render_catflw_sample.py
open ml/outputs/catflw-face-landmarks.png
```

你应检查：红点是否落在耳朵、眼睛、鼻子、口鼻与胡须附近；蓝框是否包住猫脸。

### B. 只测试 Animal Pose（身体 20 点）

```bash
cd catpose-robot   # 仓库根目录
ml/.venv/bin/python ml/scripts/render_animalpose_sample.py
open ml/outputs/animalpose-cat-keypoints.png
```

你应检查：红点是否落在耳朵、眼睛、前后肢、爪子、背部及尾巴根部附近；蓝线是否合理连接身体。

## 怎么理解测试结果？

这些图片显示的是**人工标注的正确答案（ground truth）**，不是 AI 的预测结果。

```text
现在：图片 + 人工关键点 → 程序成功读取并显示
下一步：图片 → AI 预测关键点 → 和人工关键点比较误差
之后：连续关键点 → 状态估计 → XAI 解释
```

如果脚本显示 `Ready for landmark-training setup.`，说明数据格式已准备好，可以进入“训练脸部模型”或“训练身体模型”的下一阶段。

## 常见问题

- `No such file or directory`：先确认你已经运行了上方的 `cd` 命令。
- `Permission denied`：运行 `chmod +x ml/scripts/run_dataset_tests.sh` 后再试。
- 没有打开图片：不用担心，直接在 Finder 打开 `ml/outputs/` 内的 PNG 文件。
